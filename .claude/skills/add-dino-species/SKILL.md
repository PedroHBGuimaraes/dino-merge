# Add a dino species to the merge chain

This project's 32-level fusion chain lives entirely in
`scripts/dino_chain.gd` — the `SPECIES` array, ordered smallest to
largest. Adding a species is two steps: get the sprite in place, add
one line to the array.

## 1. Sprite

The chain only uses the **adult** sprite per species (`_filhote`/
`_jovem` stages exist in `assets/dino/` from an earlier prototype but
aren't currently wired into this game). Place the new sprite at:

```
assets/dino/dino_<species_id>_adulto.png
```

- `<species_id>` is lowercase, no spaces (matches the other 32:
  `trex`, `triceratops`, `mosasaurus`, ...).
- Match the existing pixel-art style — same canvas size class as the
  others (they're all 64x64; check with a quick image-size read if
  unsure) and the same side-view framing. If you need to *generate*
  the sprite rather than use a supplied file, use the PixelLab MCP
  (`create_object` or `create_character`) with one of the existing
  `assets/dino/dino_*_adulto.png` files passed as a style reference —
  don't invent a different art style.
- `.import` files are auto-generated by the Godot editor on next open;
  you don't need to create one by hand.

## 2. Register it in the chain

Open `scripts/dino_chain.gd` and add the new `species_id` to the
`SPECIES` array, in the position matching where it should sit in the
small-to-large progression (the array order *is* the merge order —
item `i` merges with item `i` to produce item `i+1`).

If the display name shouldn't just be `species_id.capitalize()` (e.g.
it needs a hyphen or unusual casing, like `"trex" -> "T-Rex"`), add an
entry to the `DISPLAY_NAMES` dict right above `SPECIES`.

Do not touch `MIN_RADIUS`, `RADIUS_STEP`, or the score formula unless
asked — those derive every level's size/score automatically from its
position in `SPECIES`, so inserting a name is enough to reflow the
whole chain. Note that inserting (rather than appending) shifts every
later level's size/score by one step, which is expected.

## 3. Sanity check

- Confirm `assets/dino/dino_<species_id>_adulto.png` exists and the
  filename matches the `species_id` exactly (the loader in
  `dino_chain.gd`'s `_try_load_texture` builds the path from the id —
  a typo means silent fallback to the placeholder circle, not an
  error).
- If you have `gdlint` available, it runs automatically via this
  project's PostToolUse hook after you edit `dino_chain.gd`.
